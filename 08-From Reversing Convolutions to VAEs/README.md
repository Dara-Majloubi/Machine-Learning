# From Reversing Convolutions to VAEs

Implementation and exploration of convolutional auto-encoders and variational auto-encoders using PyTorch.

## Overview

This project explores auto-encoder architectures for unsupervised representation learning and image reconstruction.

The notebook starts with techniques for reversing convolutional operations and visualising intermediate CNN features. It then develops convolutional auto-encoders and extends them to variational auto-encoders with probabilistic latent representations.

## Reversing Convolutional Operations

The project implements wrapper modules that provide an `undo` operation for selected neural-network layers.

The implementation covers:

- ReLU
- Max Pooling
- Convolutional Layers

The goal is to reconstruct information from intermediate feature representations and investigate how convolutional networks transform visual information.

## Feature Visualisation

Intermediate activations of a pretrained CNN are analysed and projected back toward the input image space.

The visualisation process demonstrates how different convolutional layers respond to image features and provides an intuitive view of hierarchical feature representations.

## Convolutional Auto-Encoder

A convolutional auto-encoder is implemented using an encoder-decoder architecture.

The encoder maps an input image to a lower-dimensional latent representation, while the decoder reconstructs the original image.

The implementation includes:

- Convolutional encoding
- Pooling
- Latent representations
- Upsampling / convolutional decoding
- Reconstruction
- End-to-end training

The model is trained on the MNIST dataset.

## Auto-Encoder Training

The project investigates the effect of:

- Input preprocessing
- Reconstruction loss
- Network architecture
- Latent representation size
- Training configuration

The trained model can reconstruct input images from their encoded representations.

## Variational Auto-Encoder

The convolutional auto-encoder is extended to a Variational Auto-Encoder (VAE).

Instead of mapping each input to a single deterministic latent vector, the encoder predicts parameters of a probability distribution.

For a Gaussian latent distribution, the encoder predicts:

- Mean
- Log variance

A latent sample is then generated using the reparameterization trick.

## Reparameterization Trick

The latent variable is sampled using a differentiable formulation based on the predicted mean and variance.

Conceptually:

`z = μ + σ · ε`

where `ε` is sampled from a standard normal distribution.

This allows gradients to propagate through the stochastic sampling operation during training.

## VAE Regularisation

The VAE introduces a regularisation term that encourages the learned latent distribution to remain close to a standard normal prior.

The training objective therefore combines:

- Reconstruction loss
- Latent-space regularisation

The relative weight of these components can affect the balance between reconstruction quality and the structure of the latent space.

## Latent-Space Generation

After training, new samples can be generated by providing latent vectors to the decoder.

The notebook demonstrates generation using:

- Zero latent vectors
- One-valued latent vectors
- Random latent vectors

This illustrates how the decoder maps points in latent space back into the image domain.
