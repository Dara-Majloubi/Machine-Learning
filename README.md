# Regression Basics with NumPy

Implementation of fundamental regression and classification techniques from first principles using NumPy.

## Overview

This project explores fundamental machine learning models and optimization techniques by implementing them using NumPy.

The notebook focuses on understanding the mathematical foundations and practical implementation of regression and classification models.

## Topics Covered

### Linear Regression

- Linear regression model
- Squared error loss
- Maximum likelihood interpretation
- Analytical least-squares solution
- Bias parameter

### Logistic Regression

- Binary classification
- Logistic likelihood
- Maximum likelihood estimation
- Gradient-based optimization
- Gradient descent

### Softmax Regression

- Multi-class classification
- One-hot encoding
- Softmax function
- Categorical likelihood
- Softmax gradients

## Implementation

The models and core operations are implemented using **NumPy**, providing a low-level understanding of the mathematical operations behind neural network and machine learning models.

The notebook also includes tests and visualisations to verify and demonstrate the implementations.

## Technologies

- Python
- NumPy
- Matplotlib
- Jupyter Notebook
