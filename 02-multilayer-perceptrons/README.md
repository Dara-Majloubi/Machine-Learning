# Multilayer Perceptrons

Implementation of core components of multilayer perceptrons and a small deep learning framework using NumPy.

## Overview

This project focuses on the implementation of fundamental building blocks required to construct and train multilayer perceptrons.

The notebook develops a modular approach to neural network implementation, with separate components for layers, activation functions, parameters, forward propagation, backward propagation, and gradient verification.

## Topics Covered

- Modular neural network design
- Module system
- Forward propagation
- Backward propagation
- Activation functions
- Gradient computation
- Numerical gradient checking
- Fully connected (Linear) layers
- Trainable parameters
- Parameter gradients
- One-hot encoding
- Neural network composition

## Implementation

The neural network components are implemented using NumPy and the provided NNumpy framework.

The implementation includes analytical gradients and numerical gradient checking to verify the correctness of backpropagation.

## Technologies

- Python
- NumPy
- NNumpy
